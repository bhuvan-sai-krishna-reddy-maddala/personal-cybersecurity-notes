# Personal Cybersecurity Notes

A running collection of my notes, write-ups, and learning material as I work through cybersecurity fundamentals — one topic, one room, and one machine at a time.

This repo is less a finished reference and more a public lab notebook: it grows as I learn, and some folders are placeholders for topics I plan to fill in as I go.

## What's in here

- **TryHackMe Write-ups** — Step-by-step notes on rooms I've completed, including the approach, tools used, and key takeaways.
- **HTB – Linux Fundamentals** — Notes from Hack The Box's Linux Fundamentals track, covering core command-line and system concepts.
- **(More coming)** — Additional folders exist for topics I'm actively moving into, such as networking fundamentals. These will fill in as I progress.

## Why this repo exists

- Keep a structured, searchable record of what I've learned instead of scattered notes
- Practice explaining security concepts clearly, not just solving challenges
- Track my own progress over time as a beginner moving into cybersecurity and networking
